# Claude Deck

Claude Code 세션을 여러 개 띄워놓고 일하기 위한 Windows 터미널입니다.
탭은 왼쪽에 세로로 쌓이고, 로컬 폴더든 SSH 서버 폴더든 골라서 바로 `claude`를 켭니다.

## 실행

Windows 10/11, Node.js 20 이상이 필요합니다.

```
git clone https://github.com/gwmage/claude-deck.git
cd claude-deck
npm install
npm start
```

켤 때마다 GitHub에 새 커밋이 있는지 확인하고, 있으면 오른쪽 아래 알림의 `업데이트…`로 받아서 다시 시작합니다(`git` 필요). 패키지가 바뀐 업데이트는 앱이 닫힌 뒤 `npm install`을 돌리는 창이 잠깐 뜹니다.

`npm install` 중 Electron 바이너리가 안 받아졌다면 `node node_modules/electron/install.js`를 한 번 실행하세요.
바로가기를 만들려면 대상을 `node_modules\electron\dist\electron.exe`, 인수를 이 폴더 경로로 지정하면 됩니다.

## 할 수 있는 것

**세션**
- 좌측 세로 탭, 서버별로 묶어서 표시. 탭에는 닫기 버튼이 없고 `⋯` 메뉴나 `Ctrl+Shift+W`로만 닫으며, 실행 중이면 한 번 더 묻습니다.
- 탭을 끌어다 놓아 순서를 바꿉니다. `Ctrl+1~9` 번호도 보이는 순서를 따라갑니다.
- 폴더: 사이드바의 `📁` 버튼(또는 빈 곳 우클릭)으로 만들고, 탭을 폴더 제목 위로 끌어다 넣거나 탭 메뉴의 `폴더로 이동`을 씁니다. 폴더는 서버와 상관없이 탭을 모으고, 제목을 눌러 접을 수 있습니다(접혀 있어도 지금 보는 탭과 확인 필요한 탭은 보임). 폴더를 지워도 안의 세션은 닫히지 않습니다.
- 사이드바 오른쪽 경계를 끌어 너비를 조절합니다. 더블클릭하면 기본 너비로 돌아갑니다.
- 상태 점: 파랑(작업 중), 초록(입력 대기), 주황(다른 탭에서 응답 완료, 확인 필요), 회색 테두리(종료).
- 창이 뒤에 있을 때 오래 걸린 응답이 끝나면 Windows 알림을 띄웁니다.
- 앱을 껐다 켜면 탭 목록이 복원되고 `이어서 시작`으로 한 번에 재개합니다.
- 탭마다 자기 대화 ID를 기록해 두고 `claude --resume <ID>`로 엽니다. 같은 폴더에 여러 탭이 있어도 각자 자기 대화로 돌아갑니다(`/clear`, `/resume`로 바꾼 대화도 따라감). 기록이 없는 탭만 `--continue`를 씁니다.
  기록은 Claude 실행 시 `--settings`로 넣는 SessionStart 훅이 남기며, `claude`로 시작하는 프로그램(claude-glm 등 래퍼 포함)에만 적용됩니다.
- 빠른 실행: 자주 쓰는 "서버 + 폴더 + 명령" 조합을 저장해두고 클릭 한 번으로 실행.

**실행 프로그램 (claude 말고 다른 명령으로 켜기)**
- 새 세션 창에서 탭마다 실행 프로그램을 고릅니다. 기본은 `claude`이고, `claude-glm`, `ccr code` 같은 명령을 "＋ 다른 프로그램 추가…"로 등록합니다.
- 로컬은 PowerShell 프로필의 함수와 별칭을, 원격은 `.bashrc`의 별칭과 함수를 그대로 쓸 수 있습니다.
- 열린 탭은 우클릭 메뉴의 `실행 프로그램 변경…`으로 바꾸고, 같은 대화를 이어서 시작할 수 있습니다.
- 목록은 설정 창에서 한 줄에 하나씩 관리합니다.

**Headroom (컨텍스트 압축 프록시)**
- 새 세션 창에서 `Headroom 적용`을 켜면 `headroom wrap claude -- <옵션>` 형태로 실행해서, Claude의 요청이 [Headroom](https://github.com/chopratejas/headroom) 프록시를 거칩니다.
- 열린 탭은 우클릭 메뉴의 `Headroom 적용` / `Headroom 해제`로 바꿉니다. 같은 대화를 이어서 다시 시작합니다.
- 세션이 도는 쪽(로컬이면 이 컴퓨터, 원격이면 서버)에 headroom이 설치되어 있어야 합니다: `pip install "headroom-ai[all]"`.
- `headroom wrap`이 지원하는 프로그램(claude, codex, aider 등)에서만 고를 수 있습니다. `claude-glm` 같은 래퍼 함수에는 적용되지 않습니다.

**원격 서버**
- `~/.ssh/config`의 Host 항목을 자동으로 읽습니다. 직접 추가도 가능 (서버 관리).
- 한 서버에 탭을 여러 개 열어도 SSH 연결은 하나를 공유합니다. 인증도 한 번.
- 원격 폴더는 새 세션 창의 `찾아보기…`로 서버 디렉터리를 탐색해서 고릅니다.
- 첫 접속 때 서버 지문을 확인하고, `known_hosts`에 있으면 그대로 통과합니다.

**세션 보존 (원격)**
- 새 세션 창에서 `세션 보존`을 켜면 Claude가 서버의 tmux 세션 안에서 돕니다. 창을 닫거나, 인터넷이 끊기거나, 컴퓨터를 꺼도 서버에서 계속 작업합니다.
- 다시 켜면 탭의 `다시 연결`로 그 화면에 그대로 붙습니다. 새 세션 창에는 서버에서 계속 돌고 있는 세션 목록이 떠서 눌러서 붙을 수도 있습니다.
- 보존 탭을 닫을 때는 "연결만 끊기"와 "서버 세션까지 종료" 중에 고릅니다.
- 이미 열린 원격 탭은 우클릭 메뉴의 `세션 보존으로 전환`으로 옮깁니다. 같은 대화를 tmux 안에서 다시 띄웁니다.
- 로컬 세션은 그 컴퓨터의 프로세스라서 컴퓨터를 끄면 같이 꺼집니다. 서버에 tmux가 없으면 `sudo apt install tmux`.

**파일 보기 (원격도 동일)**
- 터미널에 찍힌 파일 경로를 클릭하면 바로 열립니다. 원격이면 SFTP로 받아서 엽니다.
- 파일 패널(`Ctrl+Shift+E`) `최근 변경` 탭: 이 세션을 시작한 뒤 만들어지거나 바뀐 파일 목록. 새 문서가 생기면 우측 하단 알림으로 알려줍니다.
- 뷰어: Markdown 렌더링, HTML, PDF, 이미지, CSV 표, JSON, 코드/텍스트, 동영상. 오피스·한글 파일은 외부 앱으로 엽니다.
- `@` 버튼으로 파일을 Claude 입력창에 `@경로` 형태로 넣을 수 있습니다.

**복사 / 붙여넣기**
- 복사: 드래그해서 선택하면 바로 복사됩니다(기본값). `Ctrl+C`나 우클릭으로도 복사되고, 자동 복사는 설정에서 끌 수 있습니다.
- 붙여넣기: `Ctrl+V`, `Ctrl+Shift+V`, `Shift+Insert`, 우클릭 모두 됩니다. 한글 입력 상태에서도 동작합니다.
- Claude Code와 tmux는 마우스를 자기가 가져가려 하지만, Deck이 그 요청을 걸러내서 드래그가 항상 선택으로 동작합니다. Claude의 클릭과 휠을 쓰고 싶으면 설정에서 `터미널 앱에 마우스 넘기기`를 켜세요. 그때는 선택에 `Shift`가 필요합니다.
- 이미지(스크린샷)를 붙여넣으면 로컬은 임시 폴더에, 원격은 서버 `~/.claude-deck/uploads/`에 저장하고 그 경로를 입력창에 넣어줍니다.
- 탐색기에서 파일을 끌어다 놓아도 똑같이 동작합니다.
- `Ctrl+Enter`와 `Shift+Enter`는 Claude 입력창 줄바꿈.

## 창을 하나 더 띄우기

앱은 기본적으로 창 하나만 뜹니다. 세션을 켜둔 채로 새 버전을 쓰거나 작업을 나누고 싶으면 두 번째 인스턴스를 띄웁니다.

```
npm start -- --instance=2
```

- 별도 프로세스로 떠서 기존 창과 동시에 돌아갑니다. 기존 창의 세션은 그대로 유지됩니다.
- 처음 켤 때 기존 설정에서 서버 목록, 빠른 실행, 실행 프로그램, 신뢰한 서버 키를 복사해 옵니다. 탭 목록은 복사하지 않습니다.
- 이후 설정과 탭은 `%APPDATA%\claude-deck-2\`에 따로 저장되고, 창 제목에 `Claude Deck 2`로 표시됩니다.
- 보존(tmux) 세션은 새 세션 창의 "이 서버에서 계속 실행 중인 세션"에서 눌러 붙을 수 있습니다.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+Shift+T | 새 세션 |
| Ctrl+Shift+W | 세션 닫기 (확인) |
| Ctrl+1 ~ 9, Ctrl+Tab | 탭 이동 |
| Ctrl+Shift+E | 파일 패널 |
| Ctrl+C (선택 있을 때) | 복사 |
| Ctrl+V, Ctrl+Shift+V, Shift+Insert, 우클릭 | 붙여넣기 |
| Ctrl+Enter, Shift+Enter | 입력창 줄바꿈 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 글꼴 크기 |
| F12 | 개발자 도구 |

## 구조

- `main.js`: 로컬 셸(node-pty, ConPTY), SSH(ssh2), SFTP 파일 전송, 설정 저장
- `preload.js`: 렌더러에 노출하는 API
- `renderer/`: UI (xterm.js)
- 설정 파일: `%APPDATA%\claude-deck\config.json`
- 원격 파일 캐시: `%TEMP%\claude-deck\`
